NiceGadgets

An online gadget store built with React and TypeScript, featuring product browsing, filtering, shopping cart, currency conversion and an order checkout system.

DEMO: [NiceGadgets](https://nicegadgets.online/)

## ✨ Features

<div align="center">

| 🛍️ Shopping | ⚙️ Functionality |
|:---:|:---:|
| Product catalog: phones, tablets & accessories | Sorting by price, rating & newest arrivals |
| Shopping cart with quantity management | Pagination with customizable items per page |
| Similar product recommendations | Currency conversion (USD → UAH) |
| Checkout with Nova Poshta integration | Order history with tracking numbers |
| Email notifications | Responsive design & multiple languages |

</div>

## 🚀 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/Localhost-Enterprises/group-project-2026.git
cd group-project-2026
```

**2. Install dependencies**

```bash
npm install
```

**3. Start the development server**

```bash
npm run dev
```

## 📜 Available Scripts

| Command | Description |
|:---|:---|
| `npm run dev` | Start development server |
| `npm run build` | Create production build |
| `npm run lint` | Check code for linting issues |
