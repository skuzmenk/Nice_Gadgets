NiceGadgets

An online gadget store built with React and TypeScript, featuring product browsing, filtering, shopping cart, currency conversion and an order checkout system.

DEMO: [NiceGadgets](https://nicegadgets.online/)

Features

Product catalog with phones, tablets and accessories

Product sorting by price, rating and newest arrivals

Pagination with customizable items per page

Product recommendations based on similarities

Shopping cart with quantity management

Currency conversion from USD to UAH

Responsive user interface

Internationalization with multiple language support

Checkout system with Nova Poshta delivery integration

Email notifications for completed orders

Order history with tracking numbers

Product data and order management using Supabase

Getting started

Clone the repository:

git clone <repository-url>
cd <project-folder>

Install dependencies:

npm install

Start the development server:

npm start

Other commands:

npm run build creates a production build

npm run lint checks the code for linting issues

Project structure

src/
├── app/          # Application setup, routing and global styles
├── components/   # Reusable UI components
├── pages/        # Application pages
├── hooks/        # Custom React hooks
├── store/        # State management
├── shared/       # Shared utilities and configurations
├── styles/       # SCSS styles
└── main.tsx      # Application entry point

Backend and integrations

Supabase – product database and application data storage

Nova Poshta API – city and warehouse selection, delivery document creation

EmailJS – email notifications

React Query – asynchronous data fetching and caching

Main goal

To develop a functional and user-friendly online gadget store with a convenient shopping experience, modern frontend architecture and integration with external services.
